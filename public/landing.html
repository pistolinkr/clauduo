Claude를 연결하는 두 가지 방법

내 컴퓨터로 연결

Claude Code가 있다면 명령어 한 줄이면 돼요.

  • 쓰고 있는 Claude 계정으로 실행
  • 로그인 정보는 내 컴퓨터를 떠나지 않음

API 키로 바로 사용

설치 없이 웹에서 바로 시작해요.

  • Anthropic API 사용량만큼 본인 계정에 청구
  • 키는 암호화해 저장하고 언제든 삭제 가능
